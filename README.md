# TaskManagement

Trello風のカンバン方式タスク管理アプリです。

## 概要
タスクを「カード」にして、「ToDo」「作業中」「完了」のリストに並べ、
進み具合に合わせて動かせるアプリです。

## このリポジトリについて
AIエンジニア養成コースの初級課題として、開発するリポジトリです。

## 想定している顧客
フリーランスの「Aさん」（架空の人物）を顧客として想定し、
ヒアリングを模擬しながら、要件定義から開発までを進めています。

## ドキュメント
- [要件定義書](docs/requirements.md)：背景・目的、範囲の概要、各ドキュメント（機能一覧、ユースケース、画面設計、非機能要件、データ設計、技術スタック）へのリンク
