# TaskManagement
Trello風のカンバン方式託す管理アプリです。

## 概要
タスクを「カード」にして、「ToDo」「作業中」「完了」のリストに並べ、進み具合に合わせて動かせるアプリです。

## 最初に作る機能
- 3つのリスト（ToDo / 作業中 / 完了）を表示する
- カードを追加する
- カードのタイトルを修正する
- カードを削除する
- カードを別のリストへ移動する
- ブラウザを閉じても、カードが残る

## あとで追加する機能
- カードに機嫌を設定する
- カードにチェック（完了マーク）を付ける
- ラベルで色分けする
- ドラッグ＆ドロップで移動する

## 今回は作らない機能
- ログイン
- 複数のボード
- 他の人戸の共有
