# 機能一覧

タスク管理アプリ（Trello風）の機能を、「最初に作る」「将来追加する」「対象外」に分けて整理する。
各機能の操作の流れは [ユースケース](use-cases.md)、画面での見え方は [画面設計](screen-design.md) を参照。

## 1. 最初に作る機能

### 1.1 ボード・カードの基本
- ToDo / 作業中 / 完了 の3つの列を表示する
- 各列に、カードを追加できる（新しいカードは、その列の一番上に入る）
  - 追加するときに、タイトルを入力する（必須）
  - 追加するときに、色と期限日を設定できる（任意）
- カードのタイトルを修正できる
- カードを削除できる（削除前に確認メッセージを表示する）
- 追加・編集の入力中に、入力欄の外を押したときは、入力内容を確定する（空の場合は、追加しない／元のタイトルのままにする）

### 1.2 色
- カード全体の背景色を、6つ（色なし・赤・青・緑・黄・グレー）から選べる
- カードの色をあとから変更でき、色なしに戻せる

### 1.3 期限日
- カードに、期限日を設定できる（任意）
- 期限日は、カレンダーから選ぶ
- 期限日は、あとから変更でき、外すこともできる
- 期限日を設定したカードには、「期限 ○月○日」と、常に表示する（年は、今年と違うときだけ付ける）
- 期限日が過ぎたカードは、日付を赤文字で表示する（完了列のカードは除く）

### 1.4 並び替え・移動
- カードをドラッグ＆ドロップで、別の列へ移動できる
- カードをドラッグ＆ドロップで、同じ列の中で並び替えられる
- 並べた順は保存され、画面を開き直しても同じ順で表示される
- 各列の「期限順」ボタンで、その列のカードを期限の早い順に並び直せる
  - 期限日のないカードは、末尾に並ぶ
  - 並び直したあとも、手動での並び替えができる（手動が優先）

### 1.5 バックアップ
- 全てのカード（列、内容、色、期限日、並び順を含む）を、バックアップとして1つのファイルに保存できる
- 保存したバックアップファイルを読み込み、保存したときの状態に戻せる（Aさん自身で操作する）

## 2. 将来追加する機能
- カードのコピー（複製）
- 「確認待ち」列の追加
- スマホ対応
- 完了列のカードを整理する機能（アーカイブなど）

## 3. 対象外（作らないもの）
- 色の名前や意味をアプリ上で管理する機能
- 複数のボード
- ログイン・他の人との共有
- 自動バックアップ
- インターネット公開
- 完了したカードの自動削除
- 削除したカードを元に戻す機能（ゴミ箱、元に戻す）
