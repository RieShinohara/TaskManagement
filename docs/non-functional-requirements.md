# 非機能要件

機能そのものではなく、「どのような条件で動くか」「どのくらいの品質か」を定める。
機能については [機能一覧](functional-requirements.md) を参照。

## 1. 動作環境
- Windows、Chromeブラウザ
- 利用者のPC内でのみ動作し、インターネットには公開しない

## 2. データの保存
- タスクのデータはデータベースに保存する（課題の要件）
- 操作の内容は、その都度、自動で保存される（保存のための操作は不要）
- カードの並び順も保存される
- ブラウザを閉じても、データが消えない

## 3. 性能・容量
- カード数が通常100枚、最大500枚の状態で、操作に支障がないこと
- 500枚は動作保証の目安であり、上限ではない
  - 500枚を超えても、カードの追加はできる
  - 500枚を超えた場合の動作の速さは、保証しない
  - 枚数が増えたことを知らせる警告は、表示しない
- 標準の背景画像は、1枚あたり約1MB以下とする
- 自分の画像として選べるファイルは、20MBまでとする（登録するときに、横1920ピクセルに縮小して保存する）

## 4. バックアップ
- 全てのカード（列、内容、色、期限日、並び順を含む）を、ワンクリックで、1つのファイルに保存できる
- 選んだ背景の設定も含める（自分の画像は含めない）
- 保存したファイルを読み込み、保存したときの状態に戻せる
- 自動バックアップは対象外

## 5. セキュリティ
- ログイン機能は不要
- 外部に公開しない
- 自分の画像は、外部に送らず、利用者のPCの中にだけ保存する

## 6. 使いやすさ
- カードの背景色は、彩度を抑えた淡い色合いとし、文字が読みやすいこと
- 淡い色合いでも、5色（赤・青・緑・黄・グレー）が見分けられること
- 使用頻度の高い操作（移動、色の変更、期限日の設定、タイトルの修正）は、少ない操作回数で行えること
- 取り返しのつかない操作（削除、バックアップの読み込み）は、実行前に確認メッセージを表示すること
- 背景が何であっても、カードの文字が読みやすいこと（カードは不透明にし、背景画像によって文字が読みにくくならないようにする）

## 7. 権利
- 標準の背景画像は、公開リポジトリへの掲載と、商用利用が可能な画像とする
- 画像の出どころ（作成方法、作成日、ライセンスの確認内容）を記録する（`prototype/backgrounds/CREDITS.md`）
- 画像生成AIの利用規約は変更されることがあるため、再配布や商用利用の前に、最新の規約を確認する
