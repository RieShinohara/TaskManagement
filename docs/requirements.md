# 要件定義書：タスク管理アプリ（Trello風）

## 1. 背景・目的
### 1.1 背景
- フリーランスとして1人で業務を行っており、複数の案件を同時並行で進めている
- 現在はメモ帳でタスクを管理しているが、どの案件がどこまで進んでいるか分からなくなる

### 1.2 目的
- タスクを分類して見える化し、案件ごとの進み具合を把握できるようにする
- Trello風のカンバン形式で、混乱なく管理できるようにする
- 業務の効率化を図る

## 2. 利用者
Aさんのみ（1人）

## 3. 機能要件
### 3.1 最初に作る機能
- ToDo / 作業中 / 完了 の3つの列を表示する
- カードを追加する
- カードの内容（タイトル）を修正する
- カードを別の列へ移動する
- カードを削除する
- カードに色を付けられる（赤・青・緑・黄・グレーの5色）
- カードの色を後から変更できる

### 3.2 将来追加する機能
- 期限日の設定
- 期限日順の並び替え（期限日の設定が前提）
- 同じ列の中での、カードの主導並び替え（ドラッグ＆ドロップとあわせて対応）
- 「確認待ち」列の追加
- ドラッグ＆ドロップによる移動
- スマホ対応
- 完了列のカードを整理する機能（アーカイブなど）

### 3.3 対象外（作らないもの）
- 色の名前や意味をアプリ上で管理する機能
- 複数のボード
- ログイン・他の人との共有
- 自動バックアップ
- インターネット公開
- 完了したカードの自動削除

## 4. 非機能要件
### 4.1 動作環境
- Windows、Chromeブラウザ
- 利用者のPC内でのみ動作し、インターネットには公開しない

### 4.2 データの保存
- タスクのデータはデータベースに保存する（課題の要件）
- ブラウザを閉じても、データが消えない

### 4.3 性能・容量
- カード数は通常100枚、最大500枚で、操作に支障がないこと
- 500枚は動作保証の目安であり、上限ではない
　- 500枚を超えても、カードの追加はできる
　- 500枚を超えた場合の動作の速さは、保証しない
　- 枚数が増えたことを知らせる警告は、表示しない

### 4.4 バックアップ
- ワンクリックで、データをファイルに保存できる
- 自動バックアップは対象外

### 4.5 セキュリティ
- ログイン機能は不要
- 外部に公開しない

### 4.6 使いやすさ
- カードの背景色は、彩度を押さえた淡い色合いとし、文字が読みやすいこと
- 淡い色合いでも、5色（赤・青・緑・黄・グレー）が見分けられること

## 5. ユースケース
### UC-1: カードを追加する
- 利用者：Aさん
- 目的：新しいタスクを登録する
- 事前条件：ボードが表示されている
- 基本の流れ：
　1. 「ToDo」列の「カードを追加」ボタンを押す
　2. カードのタイトルを入力する
　3. 「追加」ボタンを押す
　4. ToDo列の一番上に、新しいカードが表示される
- 例外の流れ：
　- タイトルが空のまま「追加」を押したら、カードは作られず、「タイトルを入力してください」と表示される

### UC-2: カードを別の列へ移動する
- 利用者：Aさん
- 目的：タスクの進み具合に合わせて、カードを動かす
- 事前条件：1枚以上のカードが表示されている
- 基本の流れ：
　1. 動かしたいカードの「移動」ボタンを押す
　2. 移動先の列（ToDo / 作業中 / 完了）を選ぶ
　3. カードが、移動先の列の一番上に表示される
- 補足：
　- どの列からどの列へも、移動できる（順番の制限はない）
　- 移動したカードは、移動先の列の一番上に表示される

### UC-3: カードの色を変更する
- 利用者：Aさん
- 目的：案件を見分けるために、カードに色を付ける・変える
- 事前条件：1枚以上のカードが表示されている
- 基本の流れ：
　1. 色を変えたいカードの「色」ボタンを押す
　2. 付けたい色見本（色なし・赤・青・緑・黄・グレー）が表示される
　3. 付けたい色を選ぶ
　4. 色見本が閉じ、カード全体の背景色が、選んだ色に変わる
- 補足：
　- 新しく追加したカードは、色なし（白）の状態で作られる
　- 「色なし」を選ぶと色を外せる
　- 選び間違えても、もう一度、色を選び直せる
- 例外：
　- 色を選ばずに止めたいときは、画面の別な場所を押す

### UC-4: カードを削除する
- 利用者：Aさん
- 目的：不要になったカードを消す
- 事前条件：1枚以上のカードが表示されている
- 基本の流れ：
　1. 消したいカードの「削除」ボタンを押す
　2. 「本当に削除しますか？」という確認メッセージが表示される
　3. 「削除する」を押す
　4. カードが消える
- 例外の流れ：
　- 確認メッセージで「キャンセル」を押したらカードは消えず、元の画面に戻る
- 補足：
　- 削除したカードは戻せない
　- 誤って消した場合は、バックアップファイルから復元する

## 8. 受け入れ条件（完成の基準）
- ブラウザを閉じても、カードが消えない
- カードの追加・タイトル修正・別の列への移動・削除ができる
- カードに5色（赤、青、緑、黄、グレー）の色をつけ、あとから変更できる
- ToDo / 作業中 / 完了の3列と、各列のカードが、1つの画面に表示される
- ワンクリックで、データをファイルに保存できる
- カードが500枚ある状態でも、操作に支障がない
- 実際の画面で、5色の見分けやすさと文字の読みやすさを、Aさんが確認できる
- カードが500枚ある状態で、追加・移動・色の変更・削除が、遅れを感じずにできる
