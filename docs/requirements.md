# 要件定義書：タスク管理アプリ（Trello風）

この文書は、要件定義の全体像をまとめたものである。詳細は、内容ごとに別のドキュメントに分けている。

## 1. 背景・目的
### 1.1 背景
- フリーランスとして1人で業務を行っており、複数の案件を同時並行で進めている
- 現在はメモ帳でタスクを管理しているが、どの案件がどこまで進んでいるか分からなくなる

### 1.2 目的
- タスクを分類して見える化し、案件ごとの進み具合を把握できるようにする
- Trello風のカンバン形式で、混乱なく管理できるようにする
- 業務の効率化を図る

## 2. 利用者
Aさんのみ（1人）

## 4. 範囲の概要
- ToDo / 作業中 / 完了 の3つの列に、タスクをカードとして並べて管理する
- カードには、色と期限日を設定でき、ドラッグ＆ドロップで、列の間や列の中を動かせる
- 列ごとに、期限順の並び替えができる
- データはデータベースに保存し、バックアップファイルによる保存・復元ができる
- 利用者は1人で、自分のPCの中だけで使う

機能の詳細は [機能一覧](functional-requirements.md) を参照。

## 5. 受け入れ条件（完成の基準）
- ブラウザを閉じて開き直しても、カードが消えない
- ToDo / 作業中 / 完了の3列と、各列のカードが、1つの画面に表示される
- 3つの列のどれにも、カードを追加でき、新しいカードは列の一番上に表示される
- カードを追加するときに、色と期限日を設定できる（設定しなくても追加できる）
- カードのタイトルを修正できる（Enterで確定、Escで取り消し）
- カードを削除でき、削除の前に確認メッセージが表示される
- カードの背景色を、6つ（色なし・赤・青・緑・黄・グレー）から選べ、あとから変更できる
- カードに期限日を設定・変更・解除でき、設定した期限日が、カードに常に表示される
- 期限日が、「期限 ○月○日」の形で表示される（年は、今年と違うときだけ付く）
- 期限日が過ぎたカードの日付が、赤文字で表示される（完了列のカードは除く）
- 追加・編集の入力中に、入力欄の外を押すと、文字があれば確定し、空なら消える（編集では、元のタイトルのままになる）
- カードをドラッグ＆ドロップで、別の列へ移動でき、同じ列の中でも並び替えられる
- 並べた順が保存され、画面を開き直しても、同じ順で表示される
- 各列の「期限順」ボタンで、その列のカードが、期限の早い順に並び直る（期限日のないカードは末尾）
- 実際の画面で、5色の見分けやすさと文字の読みやすさを、Aさんが確認できる
- ワンクリックで、全てのカードを1つのファイルに保存できる
- 保存したファイルを読み込むと、保存したときの列、カードの内容、色、期限日、並びが、再現される
- カードが500枚ある状態で、追加・移動・色の変更・削除が、遅れを感じずにできる
