# 要件定義書：タスク管理アプリ（Trello風）

## 1. 背景・目的
### 1.1 背景
- フリーランスとして1人で業務を行っており、複数の案件を同時並行で進めている
- 現在はメモ帳でタスクを管理しているが、どの案件がどこまで進んでいるか分からなくなる

### 1.2 目的
- タスクを分類して見える化し、案件ごとの進み具合を把握できるようにする
- Trello風のカンバン形式で、混乱なく管理できるようにする
- 業務の効率化を図る

## 2. 利用者
Aさんのみ（1人）

## 3. 機能要件
### 3.1 最初に作る機能
- ToDo / 作業中 / 完了 の3つの列を表示する
- 各列に、カードを追加できる（新しいカードは、その列の一番上に入る）
- カードのタイトルを修正できる
- カードを別の列へ移動できる（移動したカードは、移動先の列の一番上に入る）
- カードを削除できる（削除前に確認メッセージを表示する）
- カード全体の背景色を、6つ（色なし・赤・青・緑・黄・グレー）から選べる
- カードの色をあとから変更でき、色なしに戻せる
- 全てのカード（列、内容、色を含む）を、バックアップとして1つのファイルに保存できる
- 保存したバックアップファイルを読み込み、保存したときの状態に戻せる（Aさん自身で操作する）

### 3.2 将来追加する機能
- カードのコピー（複製）
- 期限日の設定
- 期限日順の並び替え（期限日の設定が前提）
- 同じ列の中での、カードの手動並び替え（ドラッグ＆ドロップとあわせて対応）
- 「確認待ち」列の追加
- ドラッグ＆ドロップによる移動
- スマホ対応
- 完了列のカードを整理する機能（アーカイブなど）

### 3.3 対象外（作らないもの）
- 色の名前や意味をアプリ上で管理する機能
- 複数のボード
- ログイン・他の人との共有
- 自動バックアップ
- インターネット公開
- 完了したカードの自動削除
- 削除したカードを元に戻す機能（ゴミ箱、元に戻す）

## 4. 非機能要件
### 4.1 動作環境
- Windows、Chromeブラウザ
- 利用者のPC内でのみ動作し、インターネットには公開しない

### 4.2 データの保存
- タスクのデータはデータベースに保存する（課題の要件）
- 操作の内容は、その都度、自動で保存される（保存のための操作は不要）
- ブラウザを閉じても、データが消えない

### 4.3 性能・容量
- カード数が通常100枚、最大500枚の状態で、操作に支障がないこと
- 500枚は動作保証の目安であり、上限ではない
  - 500枚を超えても、カードの追加はできる
  - 500枚を超えた場合の動作の速さは、保証しない
  - 枚数が増えたことを知らせる警告は、表示しない

### 4.4 バックアップ
- 全てのカード（列、内容、色を含む）を、ワンクリックで、1つのファイルに保存できる
- 保存したファイルを読み込み、保存したときの状態に戻せる
- 自動バックアップは対象外

### 4.5 セキュリティ
- ログイン機能は不要
- 外部に公開しない

### 4.6 使いやすさ
- カードの背景色は、彩度を抑えた淡い色合いとし、文字が読みやすいこと
- 淡い色合いでも、5色（赤・青・緑・黄・グレー）が見分けられること
- 使用頻度の高い操作（移動、色の変更、タイトルの修正）は、少ない操作回数で行えること
- 取り返しのつかない操作（削除、バックアップの読み込み）は、実行前に確認メッセージを表示すること

## 5. ユースケース
### UC-1: カードを追加する
- 利用者：Aさん
- 目的：新しいタスクを登録する
- 事前条件：ボードが表示されている
- 基本の流れ：
  1. 追加したい列の右上にある「＋」ボタンを押す
  2. その列の一番上に、タイトル入力欄のついた、新しいカードが表示される
  3. カードのタイトルを入力する
  4. Enterキーを押して確定する
  5. 入力したタイトルのカードが、その列の一番上に残る
- 例外の流れ：
  - タイトルが空のままEnterキーを押したら、カードは作られず、入力欄が消える
  - 入力中にEscキーを押したら、カードは作られず、入力欄が消える
- 補足：
  - ToDo / 作業中 / 完了 の、どの列にも追加できる
  - 新しく追加したカードは、色なし（白）の状態で作られる

### UC-2: カードを別の列へ移動する
- 利用者：Aさん
- 目的：タスクの進み具合に合わせて、カードを動かす
- 事前条件：1枚以上のカードが表示されている
- 基本の流れ：
  1. 動かしたいカードにマウスを乗せ、表示された「移動」ボタンを押す
  2. 移動先の列（現在の列以外）を選ぶ
  3. カードが、移動先の列の一番上に表示される
- 補足：
  - どの列からどの列へも、移動できる（順番の制限はない）

### UC-3: カードの色を変更する
- 利用者：Aさん
- 目的：案件を見分けるために、カードに色を付ける・変える
- 事前条件：1枚以上のカードが表示されている
- 基本の流れ：
  1. 色を変えたいカードにマウスを乗せ、表示された「色」ボタンを押す
  2. カードの近くに、色見本（色なし・赤・青・緑・黄・グレー）が表示される
  3. 付けたい色を選ぶ
  4. 色見本が閉じ、カード全体の背景色が、選んだ色に変わる
- 補足：
  - 「色なし」を選ぶと、色を外せる
  - 選び間違えても、もう一度、色を選び直せる
- 例外の流れ：
  - 色を選ばずに止めたいときは、画面の別の場所を押す

### UC-4: カードを削除する
- 利用者：Aさん
- 目的：不要になったカードを消す
- 事前条件：1枚以上のカードが表示されている
- 基本の流れ：
  1. 消したいカードにマウスを乗せ、表示された「編集」アイコンを押す
  2. メニューが表示されるので、「削除」を選ぶ
  3. 「本当に削除しますか？」という確認メッセージが表示される
  4. 「削除する」を押す
  5. カードが消える
- 例外の流れ：
  - 確認メッセージで「キャンセル」を押したら、カードは消えず、元の画面に戻る
- 補足：
  - 削除したカードは戻せない
  - 誤って消した場合は、バックアップファイルから復元する（UC-7）

### UC-5: カードのタイトルを修正する
- 利用者：Aさん
- 目的：タイトルの入力ミスや、内容の変更を反映する
- 事前条件：1枚以上のカードが表示されている
- 基本の流れ：
  1. 修正したいカードにマウスを乗せ、表示された「編集」アイコンを押す
  2. カードのタイトルが、書き換えられる状態になる（同時に、削除を含むメニューが表示される）
  3. タイトルを書き換える
  4. Enterキーを押して確定する
  5. カードに、書き換えたタイトルが表示される
- 例外の流れ：
  - 書き換え中にEscキーを押したら、変更は反映されず、元のタイトルのままになる
  - タイトルを空にしてEnterキーを押したら、変更は反映されず、元のタイトルのままになる

### UC-6: バックアップを保存する
- 利用者：Aさん
- 目的：データが失われたときに備えて、全てのカードをファイルに残す
- 事前条件：ボードが表示されている
- 基本の流れ：
  1. 画面右上の「バックアップ」ボタンを押す
  2. 全てのカード（列、内容、色を含む）が、1つのファイルとして保存される
- 補足：
  - 日々の操作は、自動で保存される。「バックアップ」ボタンは、別の場所にファイルとして残すためのものである
  - ファイルの名前には、保存した日時が付く

### UC-7: バックアップを読み込んで元に戻す
- 利用者：Aさん
- 目的：誤ってカードを消したときなどに、保存した時点の状態に戻す
- 事前条件：UC-6で保存した、バックアップファイルがある
- 基本の流れ：
  1. 画面右上の「読み込み」ボタンを押す
  2. バックアップファイルを選ぶ
  3. 「現在のデータは、すべて置き換わります。よろしいですか？」という確認メッセージが表示される
  4. 「読み込む」を押す
  5. ボードが、バックアップを保存したときの状態に戻る
- 例外の流れ：
  - 確認メッセージで「キャンセル」を押したら、何も変わらず、元の画面に戻る
  - バックアップファイルではないファイルを選んだら、「このファイルは読み込めません」と表示され、現在のデータは変わらない
- 補足：
  - 読み込むと、読み込む前のデータは、元に戻せない

## 6. 画面構成
### 6.1 画面一覧
- ボード画面（1画面のみ）

### 6.2 ボード画面の構成
画面の右上に、「バックアップ」ボタンと「読み込み」ボタンを置く。その下に、3つの列を横に並べる。

| ToDo　＋ | 作業中　＋ | 完了　＋ |
|---|---|---|
| カード | カード | カード |
| カード | カード | カード |

- 各列の右上に、カードを追加する「＋」ボタンを置く
- 新しいカードは、その列の一番上に入る

### 6.3 カードの表示と操作
- カードには、タイトルを表示する
- カードにマウスを乗せると、カードの下側に、次のアイコンが表示される（マウスを離すと消える）

| アイコン | 役割 | 押したときの動作 |
|---|---|---|
| 色 | 色の変更 | カードの近くに、色見本（6つ）が表示される |
| 移動 | 別の列へ移動 | 移動先の列を選ぶ |
| 編集 | タイトルの修正と、メニュー | タイトルが書き換え可能になり、同時に、メニュー（削除）が表示される |

- 色見本の「色なし」は、白で表示し、色を外す役割を持つ

### 6.4 カード追加時の表示
- 「＋」ボタンを押すと、その列の一番上に、入力欄のついたカードが表示される
- 入力欄には、「タイトルを入力してください」という案内文を薄く表示する
- 入力できる状態（カーソルが点滅した状態）にする

## 8. 受け入れ条件（完成の基準）
- ブラウザを閉じて開き直しても、カードが消えない
- ToDo / 作業中 / 完了の3列と、各列のカードが、1つの画面に表示される
- 3つの列のどれにも、カードを追加でき、新しいカードは列の一番上に表示される
- カードのタイトルを修正できる（Enterで確定、Escで取り消し）
- カードを、どの列からどの列へも移動でき、移動先の列の一番上に表示される
- カードを削除でき、削除の前に確認メッセージが表示される
- カードの背景色を、6つ（色なし・赤・青・緑・黄・グレー）から選べ、あとから変更できる
- 実際の画面で、5色の見分けやすさと文字の読みやすさを、Aさんが確認できる
- ワンクリックで、全てのカードを1つのファイルに保存できる
- 保存したファイルを読み込むと、保存したときの列、カードの内容、色、並びが、再現される
- カードが500枚ある状態で、追加・移動・色の変更・削除が、遅れを感じずにできる
