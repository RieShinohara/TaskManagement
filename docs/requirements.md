# 要件定義書：タスク管理アプリ（Trello風）

## 1. 背景・目的
### 1.1 背景
- フリーランスとして1人で業務を行っており、複数の案件を同時並行で進めている
- 現在はメモ帳でタスクを管理しているが、どの案件がどこまで進んでいるか分からなくなる

### 1.2 目的
- タスクを分類して見える化し、案件ごとの進み具合を把握できるようにする
- Trello風のカンバン形式で、混乱なく管理できるようにする
- 業務の効率化を図る

## 2. 利用者
Aさんのみ（1人）

## 3. 機能要件
### 3.1 最初に作る機能
- ToDo / 作業中 / 完了 の3つの列を表示する
- カードを追加する
- カードの内容（タイトル）を修正する
- カードを別の列へ移動する
- カードを削除する
- カードに色を付けられる（赤・青・緑・黄・グレーの5色）
- カードの色を後から変更できる

### 3.2 将来追加する機能
- 期限日の設定
- 「確認待ち」列の追加
- ドラッグ＆ドロップによる移動
- スマホ対応

### 3.3 対象外（作らないもの）
- 色の名前や意味をアプリ上で管理する機能
- 複数のボード
- ログイン・他の人との共有
- 自動バックアップ
- インターネット公開

## 4. 非機能要件
### 4.1 動作環境
- Windows、Chromeブラウザ
- 利用者のPC内でのみ動作し、インターネットには公開しない

### 4.2 データの保存
- タスクのデータはデータベースに保存する（課題の要件）
- ブラウザを閉じても、データが消えない

### 4.3 性能・容量
- カード数は通常100枚、最大500枚で、操作に支障がないこと

### 4.4 バックアップ
- ワンクリックで、データをファイルに保存できる
- 自動バックアップは対象外

### 4.5 セキュリティ
- ログイン機能は不要
- 外部に公開しない

## 8. 受け入れ条件（完成の基準）
- ブラウザを閉じても、カードが消えない
- カードの追加・タイトル修正・別の列への移動・削除ができる
- カードに5色（赤、青、緑、黄、グレー）の色をつけ、あとから変更できる
- ToDo / 作業中 / 完了の3列と、各列のカードが、1つの画面に表示される
- ワンクリックで、データをファイルに保存できる
- カードが500枚ある状態でも、操作に支障がない
