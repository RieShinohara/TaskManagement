# 画面設計

画面の構成、表示、操作を定める。
操作の流れは [ユースケース](use-cases.md)、機能の一覧は [機能一覧](functional-requirements.md) を参照。

## 1. 画面一覧
- ボード画面（1画面のみ）

## 2. ボード画面の構成
画面の右上に、「バックアップ」ボタンと「読み込み」ボタンを置く。その下に、3つの列を横に並べる。

| ToDo　［期限順］［＋］ | 作業中　［期限順］［＋］ | 完了　［期限順］［＋］ |
|---|---|---|
| カード | カード | カード |
| カード | カード | カード |

- 各列の上部に、列の名前、「期限順」ボタン、カードを追加する「＋」ボタンを置く
- 新しいカードは、その列の一番上に入る
- 全体は、淡い色合いで、すっきりとした見た目にする

## 3. カードの表示と操作
### 3.1 カードの表示
- カードには、タイトルを表示する
- 期限日を設定したカードには、日付を常に表示する
  - 期限日が今日より前で、完了列以外にあるカードは、日付を赤文字にする
- カード全体の背景に、選んだ色を表示する（色なしは白）

### 3.2 マウスオーバーで出るアイコン
カードにマウスを乗せると、カードの下側に、次のアイコンが表示される（マウスを離すと消える）。

| アイコン | 役割 | 押したときの動作 |
|---|---|---|
| 色（パレット） | 色の変更 | カードの近くに、色見本（6つ）が表示される |
| 期限（カレンダー） | 期限日の設定・変更 | カードの近くに、カレンダーが表示される |
| 編集 | タイトルの修正と、メニュー | タイトルが書き換え可能になり、同時に、メニュー（削除）が表示される |

- 色見本の「色なし」は、白で表示し、色を外す役割を持つ
- カレンダーには、期限日を外す操作を用意する
- 期限日を設定済みのカードは、日付を押しても、カレンダーが表示される

### 3.3 ドラッグ＆ドロップ
- カードは、マウスでつかんで動かせる
- 別の列へも、同じ列の中でも、動かせる
- カードを動かしたあとの位置は、保存される
- 「移動」ボタンは設けない（ドラッグ＆ドロップで動かす）

## 4. カード追加時の表示
- 「＋」ボタンを押すと、その列の一番上に、入力欄のついたカードが表示される
- 入力欄には、「タイトルを入力してください」という案内文を薄く表示する
- 入力できる状態（カーソルが点滅した状態）にする
- 入力欄の横に、「色」「期限」の小さなアイコンを並べる（設定は任意）
- Enterキーで確定し、Escキーで取り消す

## 5. 確認メッセージ
| 場面 | メッセージ | ボタン |
|---|---|---|
| カードの削除 | 本当に削除しますか？ | 削除する / キャンセル |
| バックアップの読み込み | 現在のデータは、すべて置き換わります。よろしいですか？ | 読み込む / キャンセル |

## 6. 未決定の事項（プロトタイプで確認して決める）
- ドラッグ中のカードの見た目（半透明にするかなど）
- ドロップ先を示す目印（線や枠を出すかなど）
- 期限日の表示形式（例：3/15、2026/3/15）
- アイコンの具体的な見た目
