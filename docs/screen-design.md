# 画面設計

画面の構成、表示、操作を定める。
操作の流れは [ユースケース](use-cases.md)、機能の一覧は [機能一覧](functional-requirements.md) を参照。

## 1. 画面一覧
- ボード画面（1画面のみ）

## 2. ボード画面の構成
画面の上部（ヘッダー）に、見出し「タスク管理」と、検索のフォーム（2.1）、「背景」ボタン、「バックアップ」ボタン、「読み込み」ボタンを置く。その下に、3つの列を横に並べる。

| ToDo　［期限順］［＋］ | 作業中　［期限順］［＋］ | 完了　［期限順］［＋］ |
|---|---|---|
| カード | カード | カード |
| カード | カード | カード |

- 各列の上部に、列の名前、「期限順」ボタン、カードを追加する「＋」ボタンを置く
- 新しいカードは、その列の一番上に入る
- 全体は、淡い色合いで、すっきりとした見た目にする
- 列の幅は固定とし、画面を広げても、列は広がらない（目安：約320px）
- ボードの外側の背景は、ほぼ白とし、列の背景は、淡い色にする（列には、薄い枠線を付ける）
- カードを読み込んでいる間は「読み込み中…」と表示する。カードのない列には「カードがありません」と表示する

### 2.1 検索
ヘッダーに、カードを絞り込む検索のフォームを置く。

| 項目 | 内容 |
|---|---|
| キーワード | 入力欄。案内文は「タイトルに含む文字」。タイトルに、その文字を含むカードだけを表示する（大文字小文字は区別しない） |
| 期限（この日まで） | 日付の入力欄（ブラウザ標準）。期限日がその日以前のカードだけを表示する（期限日のないカードは表示しない） |
| 「検索」ボタン | 押す（Enterキーでもよい）と、絞り込む。入力しただけでは、絞り込まない |
| 「クリア」ボタン | 入力を空にして、すべてのカードを表示する |

- キーワードと期限は、組み合わせて使える（両方に合うカードだけを表示する）
- 絞り込み中は、画面に出ているのが一部のカードだけで、「何番目」が決められないため、カードをドラッグ＆ドロップで動かせない。ヘッダーの下に、「絞り込み中のため、カードは動かせません。「クリア」を押すと、動かせるようになります。」と表示する
- 絞り込み中でも、カードの追加、編集、削除、「期限順」ボタンは使える

## 3. カードの表示と操作
### 3.1 カードの表示
- カードには、タイトルを表示する
- 説明文があるカードには、説明文の目印（三本線のアイコン）を表示する。説明文そのものは、一覧には表示しない
- カードを押すと、モーダル（3.2）が開く
- 期限日を設定したカードには、「期限 ○月○日」と、常に表示する（年は、今年と違うときだけ付ける）
  - 期限日が今日より前で、完了列以外にあるカードは、日付を赤文字にする（「完了列」は、名前が「完了」の列）
- カード全体の背景に、選んだ色を表示する（色なしは白）
- カードには、淡い影を付ける。マウスを乗せると、影が強くなる
- 文字の大きさは、読みやすさを優先する（目安：基本の文字は16px）

### 3.2 カードを編集するモーダル
カードを押すと、画面の中央に、モーダル（画面の上に重なって開く窓）が開く。見出しは「カードを編集」。背景は、暗くする。マウスを乗せたときに出るアイコンは、設けない。

| 項目 | 内容 |
|---|---|
| タイトル | 1行の入力欄（255文字まで）。空のままでは保存できない（「タイトルを入力してください」と赤字で表示する）。変換中でないときの Enter で保存する |
| 説明文 | 複数行の入力欄（2000文字まで）。案内文は「説明を入力してください」 |
| 色 | 色見本（6つ）。選んでいる色には、印を付ける |
| 期限 | 「期限 ○月○日」（未設定は「期限なし」）の欄を押すと、欄のすぐ下に、月のカレンダー（5章）が開く |
| ボタン | 「保存」「キャンセル」「削除」 |

- 色見本の「色なし」は、白で表示し、色を外す役割を持つ
- 「保存」を押すと、変更が反映されて、モーダルが閉じる。変更が1つもなければ、保存の通信は行わない
- 「キャンセル」、Escキー、窓の外を押したときは、変更を捨てて閉じる。ただし、保存や削除の通信中は、閉じない
- 「削除」を押すと、モーダルの中で、ボタンの部分が確認の表示（7章）に入れ替わる。「削除する」を押すと、カードが消えて、モーダルが閉じる
- 開いたときは、タイトルの入力欄にカーソルを置く
- 保存に失敗したときは、モーダルを閉じずに、エラーを表示する（入力内容は残す）

### 3.3 ドラッグ＆ドロップ
- カードは、マウスでつかんで動かせる
- 別の列へも、同じ列の中でも、動かせる
- カードを動かしたあとの位置は、保存される
- 「移動」ボタンは設けない（ドラッグ＆ドロップで動かす）
- カードを短く押しただけのときは、モーダルが開く。つかんで動かしたときは、モーダルは開かず、カードが動く
- 列のすき間や余白で離したときは、いちばん近い列に入る。つかんでいる間に Esc キーを押すと、移動を取り消して、元の位置に戻る
- キーボードでも動かせる：カードに移動して、Space キーでつかみ、矢印キーで動かし、Space キーで置く。Esc キーで取り消す。Enter キーは、モーダルを開く。つかんだときや動かしたときは、スクリーンリーダー向けに、日本語で状況を読み上げる
- 保存に失敗したときは、元の位置に戻して、エラーを表示する
- 絞り込み中（2.1）は、動かせない

## 4. カード追加時の表示
- 「＋」ボタンを押すと、その列の一番上に、入力欄のついたカードが表示される
- 入力欄には、「タイトルを入力してください」という案内文を薄く表示する
- 入力できる状態（カーソルが点滅した状態）にする
- 入力欄の下に、色見本（6つの丸）と、期限のボタン（「期限なし」、設定後は「期限 ○月○日」）を並べる（設定は任意）
- Enterキーで確定し、Escキーで取り消す
- その下に、「Enterで追加　Escで取り消し」と案内を表示する
- 説明文は、追加のときには入力しない（追加したあと、カードを押して開くモーダルで入力する）
- 入力欄の外を押したときは、タイトルが入力されていれば確定し、空であれば入力欄が消える
- 色や期限の操作をしても、入力欄は閉じず、入力を続けられる

## 5. カレンダー
- 追加のときは「期限」ボタンの、モーダルでは期限の欄の、すぐ下に表示する（下に入らないときは、上に表示する）
- 上部に「○年○月」と、前の月・次の月に移るボタン（＜、＞）を置く
- 曜日（日〜土）を表示し、日曜は赤、土曜は青で表示する
- 日付は、6週間分を表示する（月が変わっても、カレンダーの高さは変わらない）。表示している月の外の日付は、薄く表示する
- 今日の日付には枠線を付け、選択中の日付は強調して表示する
- 日付を押すと、すぐに選ばれて、カレンダーが閉じる
- 下部に「期限を外す」ボタンを置く
- カレンダーの外を押すか、Escキーを押すと、何も選ばずに閉じる（モーダルの中では、カレンダーだけが閉じ、モーダルは開いたまま）

## 6. 背景
### 6.1 背景の選択
- 画面右上の「背景」ボタンを押すと、カードの近くに出る窓と同じ、小さな窓が開く
- 窓には、見本と名前を並べた、次の5つの選択肢を表示する：無地、青空、夕焼け、星空、自動（時間帯）
- 今の背景は、選択された状態で表示する（初めて開いたときの背景は、青空）
- 背景を選ぶと、すぐに切り替わり、窓が閉じる。窓の外を押すか、Escキーを押すと、何も選ばずに閉じる
- 青空・夕焼け・星空の行には、「画像を選ぶ」ボタンを置く。画像を登録済みの行には、「元に戻す」ボタンも表示する
- 登録した画像は、その行の見本にも表示する
- 「無地」「自動（時間帯）」には、「画像を選ぶ」を置かない
- 「自動（時間帯）」は、30秒ごとに時刻を見直して、背景を切り替える

### 6.2 背景の表示
- 青空・夕焼け・星空は、標準の画像を、画面いっぱいに広げて表示する（暗幕は重ねない）。画像が読み込めないときは、グラデーションで表示する
- 自分の画像を登録した背景は、その画像を、画面いっぱいに広げて表示し、薄い暗幕（黒10%）を重ねる。標準の画像より優先する
- 背景があるときは、列を少し透けさせる（約75%。星空のときは約60%）。カードは不透明のままにして、文字を読みやすくする
- 星空のときは、列を暗い紺色にして、見出しを明るい文字にする（灰色っぽく見えないようにするため）
- 画面をスクロールしても、背景は動かない（画面に固定する）

### 6.3 自分の画像の登録
- 登録できるのは、JPEG・PNG・WebP の画像で、20MBまで。画面が、横1920pxのJPEG（画質0.85）に縮小してから送る。PNGの透明な部分は、白で塗る
- 縮小したあとの画像が5MBを超えるときは、登録できない（「画像を登録できませんでした。別の画像を選んでください。」と表示する）。ふつうは数百KBなので、この制限にかかることはほとんどない
- 画像として読み込めないファイル（壊れた画像など）は、画像でないファイルと同じ扱い（7章）

## 7. 確認メッセージ
| 場面 | メッセージ | ボタン（左から） |
|---|---|---|
| カードの削除（モーダルの中に表示） | 本当に削除しますか？ ／ 削除したカードは、元に戻せません。 | キャンセル / 削除する |
| バックアップの読み込み | 現在のデータは、すべて置き換わります。よろしいですか？ | キャンセル / 読み込む |
| 画像でないファイルを選んだ | このファイルは読み込めません。画像（JPEG・PNG・WebP）を選んでください。 | 閉じる |
| 20MBを超える画像を選んだ | ファイルが大きすぎます（20MBまで）。 | 閉じる |
| バックアップでないファイルを選んだ | このファイルは読み込めません。 | 閉じる |

- 確認のボタンは、誤って押さないように、「キャンセル」を左に置き、最初にカーソルを置く
- バックアップの読み込みが成功したときは、画面の右下に「バックアップを読み込みました。」と表示する（「閉じる」で消せる）

## 8. プロトタイプで決まった事項
- ドラッグ中のカードは、半透明で表示する
- ドロップ先は、青い線で示す
- 期限日の表示形式は、「期限 ○月○日」とする（年は、今年と違うときだけ付ける）
- アイコンは、線画のアイコンとする
- 標準の背景は、ChatGPTで作成した画像（青空・夕焼け・星空）とする。標準の画像には、暗幕を重ねない

## 9. 決定した事項
- アイコンの部品（ライブラリ）は使わない。必要なアイコン（説明文の目印の三本線など）は、画面の部品の中に、自前のSVGで描く
