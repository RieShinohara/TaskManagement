# 画面設計

画面の構成、表示、操作を定める。
操作の流れは [ユースケース](use-cases.md)、機能の一覧は [機能一覧](functional-requirements.md) を参照。

## 1. 画面一覧
- ボード画面（1画面のみ）

## 2. ボード画面の構成
画面の右上に、「背景」ボタン、「バックアップ」ボタン、「読み込み」ボタンを置く。その下に、3つの列を横に並べる。

| ToDo　［期限順］［＋］ | 作業中　［期限順］［＋］ | 完了　［期限順］［＋］ |
|---|---|---|
| カード | カード | カード |
| カード | カード | カード |

- 各列の上部に、列の名前、「期限順」ボタン、カードを追加する「＋」ボタンを置く
- 新しいカードは、その列の一番上に入る
- 全体は、淡い色合いで、すっきりとした見た目にする
- 列の幅は固定とし、画面を広げても、列は広がらない（目安：約320px）
- ボードの外側の背景は、ほぼ白とし、列の背景は、淡い色にする（列には、薄い枠線を付ける）

## 3. カードの表示と操作
### 3.1 カードの表示
- カードには、タイトルを表示する
- 説明文があるカードには、説明文の目印（三本線のアイコン）を表示する。説明文そのものは、一覧には表示しない
- カードを押すと、モーダル（3.2）が開く
- 期限日を設定したカードには、「期限 ○月○日」と、常に表示する（年は、今年と違うときだけ付ける）
  - 期限日が今日より前で、完了列以外にあるカードは、日付を赤文字にする
- カード全体の背景に、選んだ色を表示する（色なしは白）
- カードには、淡い影を付ける。マウスを乗せると、影が強くなり、少し浮き上がる
- 文字の大きさは、読みやすさを優先する（目安：基本の文字は16px）

### 3.2 カードを編集するモーダル
カードを押すと、画面の中央に、モーダル（画面の上に重なって開く窓）が開く。背景は、暗くする。マウスを乗せたときに出るアイコンは、設けない。

| 項目 | 内容 |
|---|---|
| タイトル | 1行の入力欄（255文字まで）。空のままでは保存できない |
| 説明文 | 複数行の入力欄（2000文字まで）。案内文は「説明を入力してください」 |
| 色 | 色見本（6つ）。選んでいる色には、印を付ける |
| 期限 | 「期限 ○月○日」（未設定は「期限なし」）の欄を押すと、欄のすぐ下に、月のカレンダー（5章）が開く |
| ボタン | 「保存」「キャンセル」「削除」 |

- 色見本の「色なし」は、白で表示し、色を外す役割を持つ
- 「保存」を押すと、変更が反映されて、モーダルが閉じる。変更が1つもなければ、保存の通信は行わない
- 「キャンセル」、Escキー、窓の外を押したときは、変更を捨てて閉じる
- 「削除」を押すと、確認メッセージ（7章）が表示される。「削除する」を押すと、カードが消えて、モーダルが閉じる
- 開いたときは、タイトルの入力欄にカーソルを置く
- 保存に失敗したときは、モーダルを閉じずに、エラーを表示する（入力内容は残す）

### 3.3 ドラッグ＆ドロップ
- カードは、マウスでつかんで動かせる
- 別の列へも、同じ列の中でも、動かせる
- カードを動かしたあとの位置は、保存される
- 「移動」ボタンは設けない（ドラッグ＆ドロップで動かす）
- カードを短く押しただけのときは、モーダルが開く。つかんで動かしたときは、モーダルは開かず、カードが動く

## 4. カード追加時の表示
- 「＋」ボタンを押すと、その列の一番上に、入力欄のついたカードが表示される
- 入力欄には、「タイトルを入力してください」という案内文を薄く表示する
- 入力できる状態（カーソルが点滅した状態）にする
- 入力欄の横に、「色」「期限」の小さなアイコンを並べる（設定は任意）
- Enterキーで確定し、Escキーで取り消す
- 入力欄の下に、「Enterで追加　Escで取り消し」と案内を表示する
- 説明文は、追加のときには入力しない（追加したあと、カードを押して開くモーダルで入力する）
- 入力欄の外を押したときは、タイトルが入力されていれば確定し、空であれば入力欄が消える
- 色や期限のアイコンを押しても、入力欄は閉じず、入力を続けられる

## 5. カレンダー
- 追加のときは「期限」アイコンの、モーダルでは期限の欄の、すぐ下に表示する（下に入らないときは、上に表示する）
- 上部に「○年○月」と、前の月・次の月に移るボタン（＜、＞）を置く
- 曜日（日〜土）を表示し、日曜は赤、土曜は青で表示する
- 日付は、6週間分を表示する（月が変わっても、カレンダーの高さは変わらない）
- 今日の日付には枠線を付け、選択中の日付は強調して表示する
- 日付を押すと、すぐに選ばれて、カレンダーが閉じる
- 下部に「期限を外す」ボタンを置く
- カレンダーの外を押すと、何も選ばずに閉じる（モーダルの中では、カレンダーだけが閉じ、モーダルは開いたまま）

## 6. 背景
### 6.1 背景の選択
- 画面右上の「背景」ボタンを押すと、カードの近くに出る窓と同じ、小さな窓が開く
- 窓には、見本と名前を並べた、次の5つの選択肢を表示する：無地、青空、夕焼け、星空、自動（時間帯）
- 今の背景は、選択された状態で表示する（初めて開いたときの背景は、青空）
- 背景を選ぶと、すぐに切り替わり、窓が閉じる。窓の外を押すと、何も選ばずに閉じる
- 青空・夕焼け・星空の行には、「画像を選ぶ」ボタンを置く。画像を登録済みの行には、「元に戻す」ボタンも表示する
- 登録した画像は、その行の見本にも表示する
- 「無地」「自動（時間帯）」には、「画像を選ぶ」を置かない

### 6.2 背景の表示
- 青空・夕焼け・星空は、標準の画像を、画面いっぱいに広げて表示する（暗幕は重ねない）。画像が読み込めないときは、グラデーションで表示する
- 自分の画像を登録した背景は、その画像を、画面いっぱいに広げて表示し、薄い暗幕（黒20%）を重ねる。標準の画像より優先する
- 背景があるときは、列を少し透けさせる（約75%）。カードは不透明のままにして、文字を読みやすくする
- 星空のときは、列を暗い紺色にして、見出しを明るい文字にする（灰色っぽく見えないようにするため）
- 暗い背景、画像の背景のときは、画面下の注意書きを、明るい文字で表示する
- 画面をスクロールしても、背景は動かない（画面に固定する）

## 7. 確認メッセージ
| 場面 | メッセージ | ボタン |
|---|---|---|
| カードの削除 | 本当に削除しますか？ | 削除する / キャンセル |
| バックアップの読み込み | 現在のデータは、すべて置き換わります。よろしいですか？ | 読み込む / キャンセル |
| 画像でないファイルを選んだ | このファイルは読み込めません。画像（JPEG・PNG・WebP）を選んでください。 | 閉じる |
| 20MBを超える画像を選んだ | ファイルが大きすぎます（20MBまで）。 | 閉じる |

## 8. プロトタイプで決まった事項
- ドラッグ中のカードは、半透明で表示する
- ドロップ先は、青い線で示す
- 期限日の表示形式は、「期限 ○月○日」とする（年は、今年と違うときだけ付ける）
- アイコンは、線画のアイコンとする
- 標準の背景は、ChatGPTで作成した画像（青空・夕焼け・星空）とする。標準の画像には、暗幕を重ねない
