# 技術スタック

講座で指示された内容に従って、**言語・フレームワーク・データベースは確定**。それ以外の道具は、指示された技術に合わせて選んだ**案**であり、環境構築の時点で最終確認する。

## 1. 決まっている条件
- 動作環境：Windows、Chromeブラウザ
- 利用者のPC内でのみ動作する（インターネットには公開しない）
- データはデータベースに保存する（課題の要件）
- 利用者は1人、カードは通常100枚・最大500枚程度

詳細は [非機能要件](non-functional-requirements.md) を参照。

## 2. 確定（講座の指示）
| 部分 | 技術 | 備考 |
|---|---|---|
| サーバー側（バックエンド） | **Java ＋ Spring Boot** | Javaでの開発を学ぶことが、この課題の目的の一つ |
| 画面（フロントエンド） | **React** | Next.js は今回は対象外 |
| データベース | **PostgreSQL** | |

### 2.1 Java・Spring Boot を使う理由
講座の説明：学習のため。AIに任せれば何でも作れてしまうが、受講生がJavaとSpring Bootを学習したことを、転職活動で書けるようにするため。
→ 実装は、受講生が理解しながら進める。Claudeは、仕組みの説明と、コードのレビューにも力を入れる。

## 3. 選定した案（確定の指示なし。環境構築の時点で最終確認）
指示された技術に合わせて、次の構成を案とする。

| 項目 | 案 | 理由 |
|---|---|---|
| Javaのバージョン | LTS版の最新（環境構築時に確認） | 長期サポート版が安定 |
| ビルド・依存管理（サーバー側） | Maven | Spring Bootの解説で最も多く使われ、初学者向けの情報が多い |
| データベースへの接続 | Spring Data JPA ＋ PostgreSQLドライバ | SQLを直接書かずに、Javaのクラスでデータを扱える |
| データベースの構造の管理 | Flyway | テーブル定義を、ファイルとして記録・再現できる |
| 画面の開発環境 | Vite ＋ React | Reactの現在の標準的な始め方。Next.jsを使わない構成 |
| 画面側の言語 | TypeScript | 型により、サーバーとのデータの食い違いに気づきやすい（JavaScriptも選べる） |
| ドラッグ＆ドロップ | dnd-kit | React向けの定番部品 |
| 画面とサーバーの通信 | REST API（JSON） | |
| テスト | JUnit（サーバー側）、Vitest（画面側） | それぞれの標準的な選択 |
| Node.js | LTS版 | 画面側の開発に必要 |
| 開発用のPostgreSQL | Windowsに直接インストール、またはDocker | 環境構築のときに相談して決める |
