## UC-1: カードを追加する
- 利用者：Aさん
- 目的：新しいタスクを登録する
- 事前条件：ボードが表示されている
- 基本の流れ：
  1. 追加したい列の右上にある「＋」ボタンを押す
  2. その列の一番上に、タイトル入力欄のついた、新しいカードが表示される
  3. カードのタイトルを入力する
  4. 必要であれば、入力欄の下にある色見本（6つの丸）と、期限のボタンから、色と期限日を設定する
  5. Enterキーを押して確定する
  6. 入力した内容のカードが、その列の一番上に残る
- 例外の流れ：
  - タイトルが空のままEnterキーを押したら、カードは作られず、入力欄が消える
  - 入力中にEscキーを押したら、カードは作られず、入力欄が消える
  - 入力欄の外を押したら、タイトルが入力されていればカードとして確定し、空であれば入力欄が消える
- 補足：
  - ToDo / 作業中 / 完了 の、どの列にも追加できる
  - 色と期限日は、設定しなくても追加できる
  - 色を設定しなかったカードは、色なし（白）で作られる
  - 期限日を設定しなかったカードは、期限日なしで作られる
  - 説明文は、追加のときには入力しない。追加したあと、カードを押して開くモーダルで入力する（UC-5）

## UC-2: カードをドラッグ＆ドロップで動かす
- 利用者：Aさん
- 目的：タスクの進み具合や優先順位に合わせて、カードを動かす
- 事前条件：1枚以上のカードが表示されている
- 基本の流れ：
  1. 動かしたいカードを、マウスでつかむ（ドラッグを始める）
  2. 動かしたい位置（別の列、または同じ列の中）まで、カードを運ぶ
  3. マウスを離す（ドロップする）
  4. カードが、ドロップした位置に入る
- 補足：
  - どの列からどの列へも、移動できる（順番の制限はない）
  - 同じ列の中でも、並び順を変えられる
  - つかんで動かしている間は、落とす場所に、青い線が出る（置く、または Esc で取り消すと、消える）
  - 動かしたあとの位置は、保存される
  - 列の外（列と列のすき間や、余白）でマウスを離したときは、いちばん近い列の、近い位置に入る（Trello と同じ。2026-10-16 決定）
  - キーボードでも動かせる：カードに移動して Space でつかみ、矢印キーで動かし、Space で置く（Enter はモーダルを開く）
  - 検索で絞り込んでいる間（UC-13）は、動かせない
- 例外の流れ：
  - カードをつかんでいる間に Esc キーを押したら、移動を取り消して、カードは元の位置に戻る（置いたあとは、Esc では戻らない）

## UC-3: カードの色を変更する
- 利用者：Aさん
- 目的：案件を見分けるために、カードに色を付ける・変える
- 事前条件：1枚以上のカードが表示されている
- 基本の流れ：
  1. 色を変えたいカードを押す（編集のモーダルが開く。UC-5）
  2. モーダルの色見本（色なし・赤・青・緑・黄・グレー）から、付けたい色を選ぶ
  3. 「保存」を押す
  4. モーダルが閉じ、カード全体の背景色が、選んだ色に変わる
- 補足：
  - 「色なし」を選ぶと、色を外せる
  - 選び間違えても、保存の前なら、もう一度、色を選び直せる
- 例外の流れ：
  - 色を変えずに止めたいときは、「キャンセル」を押す（Escキー、モーダルの外を押しても同じ）

## UC-4: カードを削除する
- 利用者：Aさん
- 目的：不要になったカードを消す
- 事前条件：1枚以上のカードが表示されている
- 基本の流れ：
  1. 消したいカードを押す（編集のモーダルが開く。UC-5）
  2. モーダルの「削除」を押す
  3. モーダルの中で、ボタンの部分が入れ替わり、「本当に削除しますか？」という確認メッセージが表示される
  4. 「削除する」を押す
  5. カードが消えて、モーダルも閉じる
- 例外の流れ：
  - 確認メッセージで「キャンセル」を押したら、カードは消えず、編集のモーダルに戻る（「キャンセル」が左で、最初にカーソルがある）
- 補足：
  - 削除したカードは戻せない
  - 誤って消した場合は、バックアップファイルから復元する（UC-7）

## UC-5: カードのタイトル・説明文を修正する（編集のモーダル）
- 利用者：Aさん
- 目的：タイトルの入力ミスや内容の変更を反映する。タスクの詳しい内容を、説明文として残す
- 事前条件：1枚以上のカードが表示されている
- 基本の流れ：
  1. 修正したいカードを押す
  2. 画面の中央に、編集のモーダルが開く（タイトル、説明文、色、期限、「保存」「キャンセル」「削除」。画面設計の3.2）
  3. タイトルや説明文を書き換える（色や期限も、ここで変えられる。UC-3、UC-8）
  4. 「保存」を押す
  5. モーダルが閉じ、カードに、書き換えた内容が表示される。説明文があるカードには、目印が付く
- 例外の流れ：
  - 「キャンセル」、Escキー、モーダルの外のどれかを押したら、変更は反映されず、モーダルが閉じる
  - タイトルを空にしたら、「保存」ボタンは押せない状態になり、「タイトルを入力してください」と表示される。タイトルを入れ直して保存するか、キャンセルする
  - 保存や削除の通信中は、Escキーやモーダルの外を押しても、閉じない
  - 保存に失敗したら、エラーが表示され、モーダルは開いたまま、入力内容も残る
- 補足：
  - 説明文は任意で、2000文字まで。空にして保存すると、説明文はなくなる
  - 変更が1つもないときは、そのまま閉じられる
  - カードをつかんで動かしたときは、モーダルは開かない（UC-2）

## UC-6: バックアップを保存する
- 利用者：Aさん
- 目的：データが失われたときに備えて、全てのカードをファイルに残す
- 事前条件：ボードが表示されている
- 基本の流れ：
  1. 画面右上の「バックアップ」ボタンを押す
  2. 全てのカード（列、タイトル、説明文、色、期限日、並び順を含む）が、1つのファイルとして保存される
- 補足：
  - 日々の操作は、自動で保存される。「バックアップ」ボタンは、別の場所にファイルとして残すためのものである
  - ファイルの名前には、保存した日時が付く（例：`taskboard-backup-20261016-123456.json`）
  - 選んだ背景の設定は含まれる。自分で登録した画像は、含まれない

## UC-7: バックアップを読み込んで元に戻す
- 利用者：Aさん
- 目的：誤ってカードを消したときなどに、保存した時点の状態に戻す
- 事前条件：UC-6で保存した、バックアップファイルがある
- 基本の流れ：
  1. 画面右上の「読み込み」ボタンを押す
  2. バックアップファイルを選ぶ
  3. 「現在のデータは、すべて置き換わります。よろしいですか？」という確認メッセージが表示される
  4. 「読み込む」を押す
  5. ボードが、バックアップを保存したときの状態に戻り、右下に「バックアップを読み込みました。」と表示される
- 例外の流れ：
  - 確認メッセージで「キャンセル」を押したら、何も変わらず、元の画面に戻る
  - バックアップファイルではないファイルを選んだら、「このファイルは読み込めません」と表示され、現在のデータは変わらない
- 補足：
  - 読み込むと、読み込む前のデータは、元に戻せない
  - 読み込んでも、登録済みの自分の画像は、そのまま残る
  - 背景の設定がない古いバックアップを読み込んだら、背景は初期値の「青空」になる

## UC-8: 期限日を設定・変更する
- 利用者：Aさん
- 目的：タスクの締め切りの目安を、カードに記録する
- 事前条件：1枚以上のカードが表示されている
- 基本の流れ：
  1. 期限日を設定・変更したいカードを押す（編集のモーダルが開く。UC-5）
  2. モーダルの期限の欄（「期限なし」または「期限 ○月○日」）を押す
  3. 欄のすぐ下に、月のカレンダーが表示される（設定済みの日付は、選択された状態で表示される）
  4. 日付を押す。カレンダーが閉じ、期限の欄が、選んだ日付になる
  5. 「保存」を押す
  6. モーダルが閉じ、カードに「期限 ○月○日」と表示される
- 例外の流れ：
  - 日付を選ばずにカレンダーだけ閉じたいときは、カレンダーの外を押す（モーダルは開いたまま）
  - 期限日を変えずに止めたいときは、「キャンセル」を押す（Escキー、モーダルの外を押しても同じ）
- 補足：
  - カレンダーから「期限を外す」を選ぶと、期限日をなくせる（保存すると反映される）
  - カードを追加するときにも、期限日を設定できる（UC-1）
  - カレンダーの「＜」「＞」で、前の月・次の月に移れる
  - 日付を押すと、すぐに選ばれる（確定のボタンはない）
  - 期限日を設定したカードは、「期限 ○月○日」と、常に表示される。年は、今年と違うときだけ付ける（例：期限 2027年1月15日）
  - 期限日が今日より前で、完了列以外にあるカードは、日付が赤文字で表示される

## UC-9: 期限順に並び替える
- 利用者：Aさん
- 目的：期限の近いカードを、すぐ見つけられるようにする
- 事前条件：列に2枚以上のカードがある
- 基本の流れ：
  1. 並び替えたい列の「期限順」ボタンを押す
  2. その列のカードが、期限の早い順に並び直る
- 補足：
  - 期限日のないカードは、末尾に並ぶ。同じ期限のカードは、今の順を保つ
  - 検索で絞り込んでいる間（UC-13）も、押せる
  - 並び直したあとも、ドラッグ＆ドロップで、自由に並び替えられる（手動での並び替えが優先）
  - 並び直した結果は、保存される
  - 新しく追加したカードは、並び直したあとでも、その列の一番上に入る

## UC-10: 背景を選ぶ
- 利用者：Aさん
- 目的：気分や時間帯に合わせて、画面の雰囲気を変える
- 事前条件：ボードが表示されている
- 基本の流れ：
  1. 画面右上の「背景」ボタンを押す
  2. 見本つきの選択肢（無地・青空・夕焼け・星空・自動（時間帯））が表示される
  3. 好きな背景を選ぶ
  4. 窓が閉じ、背景が、すぐに切り替わる
- 例外の流れ：
  - 背景を選ばずに止めたいときは、画面の別の場所を押す（Escキーでもよい）
- 補足：
  - 選んだ背景は保存され、画面を開き直しても残る
  - 「自動（時間帯）」を選ぶと、5時〜16時は青空、16時〜18時は夕焼け、18時〜翌5時は星空になる。画面を開いたままでも、時間が来たら、切り替わる
  - 背景が何であっても、カードの文字は、読みやすく表示される

## UC-11: 自分の画像を、背景に登録する
- 利用者：Aさん
- 目的：お気に入りの画像を、背景にする
- 事前条件：ボードが表示されている
- 基本の流れ：
  1. 画面右上の「背景」ボタンを押す
  2. 青空・夕焼け・星空のうち、画像を割り当てたい背景の「画像を選ぶ」を押す
  3. 自分のPCから、画像のファイルを選ぶ
  4. 画像が登録され、その背景に切り替わる
- 例外の流れ：
  - 画像（JPEG・PNG・WebP）以外のファイルを選んだら、「このファイルは読み込めません」と表示し、登録しない
  - 20MBを超えるファイルを選んだら、「ファイルが大きすぎます」と表示し、登録しない
  - 縮小したあとの画像が5MBを超えるときは、「画像のファイルサイズが大きすぎて、登録できませんでした（5MBまで）。画像を圧縮するか、別の画像を選んでください。」と表示し、登録しない（ふつうは数百KBなので、ほとんど起こらない）
- 補足：
  - 3つ全部に登録しなくてもよい。登録していない背景は、標準の画像で表示される
  - 大きい画像は、横1920ピクセルに縮小して保存する。小さい画像は、拡大しない
  - 画像は、このPCの中（アプリのデータベース）にだけ保存し、外部には送らない。ブラウザを変えても、残る
  - 登録した画像には、薄い暗幕（10%）を重ね、カードの文字を読みやすくする
  - 「自動（時間帯）」のときも、その時間帯の背景に登録した画像があれば、その画像で表示される

## UC-12: 登録した画像を、元に戻す
- 利用者：Aさん
- 目的：登録した画像をやめて、標準の画像に戻す
- 事前条件：UC-11で、画像を登録している
- 基本の流れ：
  1. 画面右上の「背景」ボタンを押す
  2. 画像を登録している背景の「元に戻す」を押す
  3. 登録した画像が消え、その背景は、標準の画像に戻る
- 補足：
  - 確認メッセージは表示しない（元のファイルは、Aさんのパソコンにあり、登録し直せるため。色の変更と同じ考え方である）

## UC-13: カードを検索（絞り込み）する
- 利用者：Aさん
- 目的：たくさんのカードの中から、探しているカードや、期限の近いカードを、すぐ見つける
- 事前条件：ボードが表示されている
- 基本の流れ：
  1. 画面上部の「キーワード」に、タイトルに含まれる文字を入力する（または、「期限（この日まで）」に日付を入力する。両方でもよい）
  2. 「検索」ボタンを押す（Enterキーでもよい）
  3. 条件に合うカードだけが、各列に表示される
  4. 「クリア」ボタンを押すと、入力が空になり、すべてのカードが表示される
- 補足：
  - キーワードは、タイトルの一部と合えばよく、大文字小文字は区別しない
  - 期限は、その日以前のカードが対象で、期限日のないカードは表示されない
  - 入力しただけでは絞り込まれない。「検索」ボタンを押したときに、絞り込まれる
  - 絞り込み中は、カードをドラッグ＆ドロップで動かせない。画面に「絞り込み中のため、カードは動かせません。「クリア」を押すと、動かせるようになります。」と表示される
  - 絞り込み中でも、カードの追加、編集、削除と、「期限順」ボタンは使える
