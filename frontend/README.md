# frontend（画面）

React + TypeScript + Vite + Tailwind CSS で作る、ボード画面。

## 使い方
`frontend/` で実行する。

| やりたいこと | コマンド |
|---|---|
| 開発サーバーを起動（http://localhost:5173） | `npm run dev` |
| テスト（Vitest） | `npm test` |
| 静的チェック（oxlint） | `npm run lint` |
| 本番用にビルド | `npm run build` |

- 初めて使うときは、先に `npm install`
- 画面から `/api/...` にお願いすると、Vite が `http://localhost:8080`（バックエンド）に中継する（`vite.config.ts` の `proxy`）。そのため、**データを見るには、DBとバックエンドも起動しておく**（[backend/README.md](../backend/README.md)）
- 新しいシェルで `node` が見つからないときは、シェルを開き直す（Node.js は winget で導入）

## カードのドラッグ＆ドロップ
- カードをつかんで動かすと、別の列へも、同じ列の中でも動かせる（[dnd-kit](https://dndkit.com/) を使用）。動かした位置は、バックエンドの `PUT /api/cards/{id}/move` で保存される
- 5px 以上動かすと「つかんだ」、動かさずに離すと「押した」扱い（押すと、編集のモーダルが開く）
- 列のすき間や余白で離したときは、いちばん近い列に入る。つかんでいる間に Esc を押すと、取り消せる（置いたあとは、戻らない）
- キーボードでも動かせる：カードにフォーカスして、スペースでつかむ → 矢印キーで動かす → スペースで置く（Esc で取り消し）。Enter は、モーダルを開く
- 検索で絞り込んでいる間は、動かせない（画面に列の一部しか出ていないため、位置が決められない）。そのときは、ヘッダーの下にお知らせが出る。「クリア」を押すと、動かせる
- 並べ替えの計算は、画面から切り離して `src/lib/moveCard.ts` に置いている（バックエンドの移動と同じ考え方）

## 「期限順」ボタン
- 各列の上部（列の名前の右、「＋」の左）に「期限順」ボタンがある。押すと、その列のカードが、期限の早い順に並び直る（期限のないカードは末尾。同じ期限は今の順番のまま）。確認のメッセージは出ない
- 並べ替えと保存は、バックエンドの `POST /api/columns/{id}/sort-by-due` が行う。画面は、結果を取り直して表示する
- 絞り込み（検索）中でも押せる。並び直すのは列のカード全部で、取り直すと、絞り込んだ結果が同じ順で出る
- 並び直したあとも、ドラッグ＆ドロップで動かせる（手動が優先）

## バックアップ（保存と読み込み）
- 画面右上（検索バーの右）に、「バックアップ」と「読み込み」のボタンがある
- 「バックアップ」：全データ（列とカード）を、`taskboard-backup-日時.json` というファイルとして保存する（ブラウザのダウンロード）
- 「読み込み」：保存したファイルを選ぶと、「現在のデータは、すべて置き換わります。よろしいですか？」と確認が出る。「読み込む」を押すと、ボードがファイルの状態に戻る。**読み込む前のデータは、元に戻せない**
- バックアップファイルではないファイルを選ぶと、「このファイルは読み込めません。」と出て、データは変わらない
- 保存と読み込みは、バックエンドの `GET /api/backup`、`POST /api/backup/restore` が行う。ファイルの形式は、[docs/data-design.md](../docs/data-design.md)
- バックアップのファイルには、個人の予定が入るので、リポジトリに入れない（`.gitignore` で、`taskboard-backup-*.json` を除外している）

## 背景
- ヘッダーの「背景」ボタンを押すと、見本つきの5つ（無地・青空・夕焼け・星空・自動（時間帯））が開く。選ぶと、すぐに切り替わって窓が閉じる。窓の外・Esc では、何も選ばずに閉じる
- 選んだ背景は、バックエンドの `GET/PUT /api/settings` に保存され、開き直しても残る。バックアップにも含まれる（読み込むと、背景も戻る）
- 青空・夕焼け・星空は、標準の画像（`public/backgrounds/`、出どころは同じフォルダの `CREDITS.md`）を、画面いっぱいに固定して表示する。画像が読み込めないときは、グラデーションが代わりに見える（`src/index.css`）
- 自動（時間帯）：5時〜16時は青空、16時〜18時は夕焼け、18時〜翌5時は星空。画面を開いたままでも、30秒ごとに時刻を見直して、時間が来たら切り替わる
- 背景があるとき、列は少し透ける（約75%）。星空のときは、列が暗い紺色になり、見出しが明るい文字になる。カードは、どの背景でも不透明（文字が読める）
- 自分の画像を登録できる（下記）

## 自分の画像を背景にする
- 「背景」の窓の、青空・夕焼け・星空の行にある「画像を選ぶ」で、自分の画像（JPEG・PNG・WebP）を選ぶと、その背景に登録され、切り替わる。無地と自動には、ない
- 大きい画像は、**横1920pxに縮小したJPEG**にしてから、バックエンドに送る（小さい画像は、拡大しない）。ファイルは20MBまで。画像以外は、「このファイルは読み込めません。画像（JPEG・PNG・WebP）を選んでください。」、20MB超は「ファイルが大きすぎます（20MBまで）。」と出て、登録しない
- 登録した画像は、標準の画像より優先して、画面いっぱいに表示し、**黒20%の暗幕**を重ねる（文字を読みやすくするため）。窓の見本にも、その画像が出る。自動のときも、その時間帯に登録があれば使う
- 登録済みの行の「元に戻す」で、画像が消えて、標準の画像に戻る（確認は出ない）
- 画像は、バックエンドのDBに保存される（このPCの中だけ）。バックアップには入らず、バックアップを読み込んでも、そのまま残る
