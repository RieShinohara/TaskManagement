# frontend（画面）

React + TypeScript + Vite + Tailwind CSS で作る、ボード画面。

## 使い方
`frontend/` で実行する。

| やりたいこと | コマンド |
|---|---|
| 開発サーバーを起動（http://localhost:5173） | `npm run dev` |
| テスト（Vitest） | `npm test` |
| 静的チェック（oxlint） | `npm run lint` |
| 本番用にビルド | `npm run build` |

- 初めて使うときは、先に `npm install`
- 画面から `/api/...` にお願いすると、Vite が `http://localhost:8080`（バックエンド）に中継する（`vite.config.ts` の `proxy`）。そのため、**データを見るには、DBとバックエンドも起動しておく**（[backend/README.md](../backend/README.md)）
- 新しいシェルで `node` が見つからないときは、シェルを開き直す（Node.js は winget で導入）

## カードのドラッグ＆ドロップ
- カードをつかんで動かすと、別の列へも、同じ列の中でも動かせる（[dnd-kit](https://dndkit.com/) を使用）。動かした位置は、バックエンドの `PUT /api/cards/{id}/move` で保存される
- 5px 以上動かすと「つかんだ」、動かさずに離すと「押した」扱い（押すと、編集のモーダルが開く）
- 列のすき間や余白で離したときは、いちばん近い列に入る。つかんでいる間に Esc を押すと、取り消せる（置いたあとは、戻らない）
- キーボードでも動かせる：カードにフォーカスして、スペースでつかむ → 矢印キーで動かす → スペースで置く（Esc で取り消し）。Enter は、モーダルを開く
- 検索で絞り込んでいる間は、動かせない（画面に列の一部しか出ていないため、位置が決められない）。そのときは、ヘッダーの下にお知らせが出る。「クリア」を押すと、動かせる
- 並べ替えの計算は、画面から切り離して `src/lib/moveCard.ts` に置いている（バックエンドの移動と同じ考え方）
